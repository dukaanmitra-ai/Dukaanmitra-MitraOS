## 🚀 Quick Start

### For Developers

```bash
# Clone repository
git clone https://github.com/1nsharma/DukaanMitra_data_app.git
cd DukaanMitra-OS

# Install dependencies
npm install
cd apps/ai-services && pip install -r requirements.txt

# Run locally (with cloud services)
npm run dev
```

### For Users

1. Visit: https://dukaanmitra.in
2. Sign up with WhatsApp OTP
3. Select business template
4. Start managing your business
